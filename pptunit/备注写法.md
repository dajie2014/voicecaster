# 备注写法：讲课的口气

**这条流水线（pptx → 备注 → 配音 → 嵌回）里，备注不是「讲义稿」，是「老师站着说的话」。**
备注怎么写，配音就怎么念——书面腔会直接变成朗诵腔。

## 规则真源

完整规则、脚本、对照表在技能里：

```
~/.dsh/skills/pptx-lecture-notes/
  SKILL.md                    六条硬规则 + 工作流
  references/书面腔对照表.md    改不动的时候翻它
  scripts/dump_notes.py       导出每页备注
  scripts/check_notes.py      核对硬信息 / 跨页词 / 长度
  scripts/apply_notes.py      只写备注，页面指纹校验
```

**改备注前先加载这个技能**，不要凭印象写。

## 六条（摘要）

1. 只改备注；标题、大字、图片、图表一律不动。
2. 书面讲义 → 现场授课口语。
3. 技术信息一条不删，也不脑补新的。
4. 句子短，一句一口气；「本讲、本节」→「这节课」，多用「咱们、大家、你」。
5. 单页独立，不写跨页预告和「上一讲说过」。
6. 只交纯备注文本，不加解释。

## 在这条流水线里的位置

```
课件.pptx ──dump_notes.py──▶ 逐页改写 ──check_notes.py──▶ apply_notes.py ──▶ 备注写好
                                                                      │
                                                          build.py 切句、配音、嵌回
```

先按技能把备注写对，再跑 `build.py`。短句、口语的备注，配音出来才像上课。
